What works — and what doesn't
Intel consumer platforms can't route BAR-mapped P2P TLPs between root ports. Here's the full picture.
❌
Fails

Direct BAR P2P

GPU-to-GPU memory access via PCIe BAR windows. Causes data corruption (NaN) on Intel consumer root complexes — a silicon-level limitation.

❌
Fails

CUDA IPC

Cross-process BAR mapping also fails. vLLM's can_actually_p2p() test catches this and automatically disables custom all-reduce.

✅
Works

cudaMemcpyPeer

DMA staging through host RAM delivers ~6 GB/s throughput. Requires the patched NVIDIA driver to enable the peer DMA path.

✅
Works

NCCL SHM Transport

NCCL probes at startup, detects the P2P failure, and auto-selects shared-host-memory transport. No manual flags needed.

✅
Works

vLLM TP=2

Full tensor parallelism across two consumer GPUs. vLLM detects the P2P failure and delegates all-reduce to NCCL automatically.

✅
Works

Ollama Multi-GPU

Ollama uses the same CUDA DMA path. A systemd drop-in sets CUDA_VISIBLE_DEVICES and OLLAMA_NUM_GPU=2.

PCIe topology
Test rig: Intel i7-12700KF with 5 NVIDIA GPUs across CPU PEG and PCH lanes.
# CPU PEG lanes (direct to CPU root complex)
  00:01.0 → [01] EMPTY SLOT   (x16 electrical)
  00:01.1 → [02] GPU0: RTX 3090   Gen4 x8 · ~6.6 GB/s

# PCH lanes (cross DMI 3.0 x4 bridge — ~16 GB/s shared)
  00:1b.4 → [04] GPU1: RTX 3090   Gen4 x4 · ~6.6 GB/s
  00:1c.0 → [05] GPU2: RTX 3060   Gen1 x1 · ~0.8 GB/s  ← bandwidth-starved
  00:1c.1 → [06] GPU3: RTX 3060   Gen1 x1 · ~0.8 GB/s  ← bandwidth-starved
  00:1c.4 → [08] GPU4: RTX 3090   Gen4 x4 · ~6.6 GB/s

Environment variables
Copy-paste config for production use. These two variables are all you need.
Production (fastest)
NCCL_P2P_DISABLE =1
VLLM_SKIP_P2P_CHECK =1
Skip P2P probe entirely. Saves 5 s on startup. NCCL goes straight to SHM and optimizes aggressively. 10–15% better TPOT.
Initial validation (first run)
NCCL_P2P_DISABLE =0
VLLM_SKIP_P2P_CHECK =0
Let NCCL probe and fall back. Let vLLM test IPC and disable custom all-reduce. Confirms the auto-detection pipeline works. Use once, then switch.
What the installer does
One command handles everything — including staying alive through kernel upgrades.

Patched NVIDIA Driver

Clones aikitoria/open-gpu-kernel-modules branch 595.58.03-p2p and registers it with DKMS so the patched modules are always available.

Kernel Upgrade Safe

DKMS rebuilds the patched modules (MOK-signed, Secure Boot compatible) every time apt installs a new kernel — before you reboot. apt upgrade is safe to run any time.

apt Lockdown

An apt pin (Pin-Priority: -1) and apt-mark hold block new nvidia-driver-* and libnccl* packages from replacing the patched driver.

GRUB + modprobe

Patches GRUB with intel_iommu=on iommu=pt pci=noaer pcie_aspm=off and writes /etc/modprobe.d/nvidia.conf with RMForceP2PType=0.

vLLM Environment

Creates ~/venvs/vllm and installs the full CUDA 12.8 vLLM stack via uv. Fast, reproducible, isolated from system Python.

Health Check Script

Installs /usr/local/sbin/p2p-healthcheck for post-reboot validation. Run after any kernel update to confirm everything still works.

True BAR P2P would require AMD Threadripper / EPYC, Intel Xeon, a PLX/PEX PCIe switch, or an NVLink bridge. On Intel consumer platforms the SHM path is your best option — and with P2P probing disabled, it's surprisingly fast.
